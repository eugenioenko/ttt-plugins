# Tokyo Neon Theme

The Tokyo Neon theme from [ttt’s extra themes](https://github.com/eugenioenko/ttt/blob/ed98120c/config/themes/13-tokyo-neon.json), packaged as a theme plugin.

Requires ttt with manifest theme contributions (eugenioenko/ttt#1246).

Install **Tokyo Neon Theme** from the Plugins panel, then choose **plugins/theme-tokyo-neon/tokyo-neon** in **Switch Theme**. Installation does not change the active theme. No Lua code or permissions are needed.

Disabling the plugin keeps its theme available. Uninstalling removes the theme and returns to default colors if it was active.

The theme JSON is unchanged from ttt and is distributed under the repository’s [MIT license](../LICENSE).
