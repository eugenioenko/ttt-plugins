# lang-astro

Syntax highlighting for [Astro](https://astro.build) components (`.astro`).

Frontmatter, expressions, `<script>` and `<style>` blocks are highlighted with ttt's built-in TypeScript, JavaScript, CSS, SCSS, Sass, Less and Stylus grammars.

## What it does

When installed, this plugin copies its grammar to `~/.config/ttt/grammars/` and adds it to the `editor.grammars` setting. When uninstalled, the grammar file and settings entry are removed.

Requires a ttt version with grammar plugin support.
