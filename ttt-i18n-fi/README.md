# Suomi Language Pack

TTT's core editor interface in Finnish (`fi`).

Requires TTT 1.12.0 or later. Install **Suomi Language Pack** from the Plugins panel, choose **Change Display Language**, and restart. English remains the fallback for missing or stale messages. This declarative pack requires no Lua code or permissions.

Translations are machine-generated with the local Codex CLI; native-speaker corrections are welcome. See [language pack maintenance](../i18n/README.md) for incremental generation and validation.
