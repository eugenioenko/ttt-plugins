# Vermeer Theme

The Vermeer theme from [ttt’s extra themes](https://github.com/eugenioenko/ttt/blob/ed98120c/config/themes/01-vermeer.json), packaged as a theme plugin.

Requires ttt with manifest theme contributions (eugenioenko/ttt#1246).

Install **Vermeer Theme** from the Plugins panel, then choose **plugins/theme-vermeer/vermeer** in **Switch Theme**. Installation does not change the active theme. No Lua code or permissions are needed.

Disabling the plugin keeps its theme available. Uninstalling removes the theme and returns to default colors if it was active.

The theme JSON is unchanged from ttt and is distributed under the repository’s [MIT license](../LICENSE).
