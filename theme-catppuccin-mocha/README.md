# Catppuccin Mocha Theme

[Catppuccin Mocha](https://catppuccin.com), ported from Catppuccin's official VS Code theme ([catppuccin/vscode](https://github.com/catppuccin/vscode) 3.19.0, `themes/mocha.json`), packaged as a theme plugin.

- Its 197 `tokenColors` rules keep the same scopes and colors, so code is colored as in VS Code.
- Editor, diff line, and bracket match colors come from the same file, with their alpha blended onto the `#1e1e2e` base.
- The terminal palette follows Catppuccin's terminal ports ([catppuccin/alacritty](https://github.com/catppuccin/alacritty), [catppuccin/windows-terminal](https://github.com/catppuccin/windows-terminal)).

Requires ttt with manifest theme contributions (eugenioenko/ttt#1247).

Install **Catppuccin Mocha Theme** from the Plugins panel, then choose **plugins/theme-catppuccin-mocha/catppuccin-mocha** in **Switch Theme**. Installation does not change the active theme. No Lua code or permissions are needed.

Disabling the plugin keeps its theme available. Uninstalling removes the theme and returns to default colors if it was active.
